# 釧路イベントマップ

釧路市周辺で開催されるイベントを地図上で確認できるWebアプリです。Line連携もする予定です
主催者がイベントを開催するときに告知できる機能も実装予定です

## 概要

釧路市周辺のイベント情報を、地図を使って分かりやすく確認できるサービスを目指しています。

## 主な機能

- 地図の表示
- イベント情報の表示
- イベント開催場所をマーカーで表示
- イベントの詳細表示
- 主催者によるイベント登録
